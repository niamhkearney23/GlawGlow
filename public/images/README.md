## How to swap a photo (easiest way — straight on GitHub)

1. Open this folder on GitHub: `public/images`
2. Click **Add file → Upload files**
3. Rename each photo to match the table above before uploading (e.g. `hero.jpg`)
4. Click **Commit changes** — the live site rebuilds automatically in about a minute

To change a caption, or point a slot at a different file, edit
`src/config/content.ts`.
